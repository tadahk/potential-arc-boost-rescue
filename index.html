Rescue your Arc Boosts

Arc's help centre says Boosts can't be exported and won't move to Dia. They're still on your Mac, though. This page turns them into files that work in Zen, Firefox, Chrome, Brave, Edge, Dia and Safari.

  • Runs entirely in your browser
  • Nothing is uploaded
  • Open source

1 Find your Boosts folder

Your Boosts live in this folder on your Mac:

~/Library/Application Support/Arc/boosts

It's a hidden folder. In the next step, when the folder picker opens, press ⌘ ⇧ G, paste the path, press Return, then click Upload (or Open). Despite the button's name, nothing leaves your computer.

Prefer to do it by hand, or on Windows?

In Finder, choose Go › Go to Folder, paste the path above, and drag the boosts folder onto the drop zone below. You can also open any single Boost in Arc's Boost editor, choose its settings icon, then Open in Finder.

On Windows, Boosts were only partly supported. If you had any, look for a boosts folder inside Arc's data folder under %LOCALAPPDATA%\Packages (a folder starting with TheBrowserCompany.Arc) and drop it below.

2 Choose the folder

3 Download your rescued Boosts

    4 Install them in your new browser

    Unzip the download, then pick one route. The zip also has a README with these steps.

    Any browser easiest

    Zen, Firefox, Chrome, Brave, Edge, Dia, Safari

    1. Install Violentmonkey or Tampermonkey (on Safari, the free Userscripts app).
    2. Drag each file from the userscripts folder into a browser tab and click Install.

    Restyling Boosts

    For Boosts that only change how sites look

    1. Install Stylus.
    2. Open Stylus › Manage › Import and choose stylus-import.json.

    Chrome-based browsers

    Chrome, Brave, Edge, Dia, Vivaldi: all Boosts in one extension

    1. Open chrome://extensions and switch on Developer mode.
    2. Click Load unpacked and choose the chromium-extension folder. Keep that folder somewhere permanent.

    Questions

    Is this safe?

    The page has no server side and is locked so it cannot connect to the internet at all: everything happens in your browser tab. The code is short and public on GitHub. Only install Boosts you made or trust, since scripts run on the sites they target.

    Does it work after December 22?

    Probably, since the files stay on your Mac until you delete Arc's data. But Arc may clean up when it's removed or updated, so rescue them now.

    What doesn't come across?

    Each Boost's CSS and JavaScript, its sites and whether it was on all come across. Rare extras (a pop-up window or background script inside a Boost) can't be converted, but they're kept in the original-backup folder and listed in the README. Boosts made for Arc's own pages won't apply elsewhere.

    What about Zen's own Boosts?

    Zen has its own Boosts feature. Until it can import files, the Violentmonkey and Stylus routes work in Zen today, or you can paste a Boost's CSS from the backup folder into a new Zen Boost.

    Something didn't convert properly

    Please open an issue. If you can, attach the Boost's folder from original-backup (check it has nothing private in it first).
